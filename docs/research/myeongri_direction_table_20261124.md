**요청**: LEO 슬랙 11-24 「응 해봐 넓게」(스레드 `1793364360.433739`). 앞 문서 `docs/research/myeongri_source_taste_20261124.md`(flavor repo b0579d0)에서 이어진다.
**원문 출처**: zh.wikisource 원본 텍스트(`action=raw`). 판본이 명시돼 있지 않고 간체로 옮긴 것이 많다.
- 조사 에이전트 2회가 직접 읽었다.
- flavor가 7건을 다시 받아 대조했고 모두 일치했다. 대조한 것: 滴天髓 甲木, 三命通會 卷七 木, 素問 「心欲苦」, 淵海子平 「食神善能饮食」 「伤官主人多才艺」 「急躁如风」 「食神多而好饮食」, 三命通會 卷三 「好奇尚大」.
- **『子平真詮』은 원문을 열지 못했다**(wikisource 404, 블로그 403). 그래서 격국 칸은 비어 있다.
- 밖에 낼 때는 인쇄본 대조가 필요하다.

## 0. 앞 보고 정정

- 11-24 첫 보고에서 「엔진 대응표 중 원전과 맞는 칸은 식신 하나」라고 했다. 그 조사는 십신 장을 보지 않은 상태였다.
- 십신 원문을 보니 **엔진 `SIPSIN_FLAVOR_MAP_V2`의 방향은 대부분 원전과 맞는다**(§4).
- 엔진 근거 등급이 「실무수렴」이었던 것은 현대 실무 해설이 원전 십신 서술을 이어받았기 때문으로 보인다.

## 1. 옮기는 규칙 (결과를 보기 전에 고정)

| 우리 축 | + 로 읽는 원문 낱말 | − 로 읽는 원문 낱말 |
|---|---|---|
| **강도·자극** | 猛烈 · 剛 · 強 · 烈 · 急 · 急躁 · 好勇 · 好斗 · 好杀 · 威猛 · 如虎 | 柔 · 弱 · 溫潤 · 溫柔 · 純粹 · 慈 · 謙和 · 宽厚和平 · 优游 |
| **폭·새것** | 好奇尚大 · 博学多能 · 多才艺/多艺多能 · 好游 · 交游四海 · 好驰骋 · 迁变 · 情性不常 · 流荡 · 风流 | 守慎 · 谨守 · 宜靜 · 安静 · 固重 · 括囊 |
| **먹기 즐김** | 善/好/能饮食 · 食丰 · 好食 | (없음) |
| 씀씀이 *(통제 축)* | 慷慨 · 轻财 · 不甚吝财 | 俭约 · 悭吝 · 吝财 · 谨守貲财 |
| 향락 | 嗜酒 · 喜酒色 · 贪花 · 风流 | 清省 · 清雅 |
| 자기과시·남과 다름 | 傲物气高 · 好胜 · 心高 · 自傲 | 謙和 |

- **근거 등급**
  - **A** = 원문 또는 책 안에 실린 부(賦)·시결(詩訣). 대상: 淵海子平, 三命通會, 滴天髓 원문·원주.
  - **B** = 주석이나 개별 명식 사례. 대상: 任鐵樵 주, 窮通寶鑑의 특정 배합 문장.
  - 방향 예측의 주검정 후보는 A만 쓴다.
- 한 칸에 + 와 − 가 함께 있으면 「엇갈림」으로 적고 예측하지 않는다.
- 낱말이 그 사람의 기질이 아니라 운(부귀·화복)을 말하면 읽지 않는다.

## 2. 단위별 방향 예측

✔ = 생년월일만으로 계산할 수 있음. 엔진 `extract_features(hour=None)`이 시주를 빼고 계산한다.

### 2-1. 일간 10종 ✔ — **원전끼리 엇갈린다**

| 일간 | 滴天髓 원문 | 淵海子平 愛憎賦 | 강도 |
|---|---|---|---|
| 甲 | 參天(원주 「參天雄壯」) | 甲乙 「仁慈大量」 | 엇갈림 |
| 乙 | 雖柔 | 甲乙 「仁慈大量」 | − |
| 丙 | **猛烈**, 欺霜侮雪 | 丙丁 「威风气猛」 | **+** |
| 丁 | **柔中**, 內性昭融 | 丙丁 「威风气猛」 | **엇갈림** |
| 戊 | 固重, 怕沖宜靜 | — | 강도 0 · 폭 − |
| 己 | 卑濕, 中正蓄藏 | — | 0 |
| 庚 | 帶煞, **剛強為最** | 庚辛 「果断气刚」 | **+** |
| 辛 | **軟弱**, 溫潤而清 | 庚辛 「果断气刚」 | **엇갈림** |
| 壬 | 汪洋, 剛中之德, **周流不滯** | 壬癸 「谋略大」 | 폭 +(약) |
| 癸 | **至弱** | 壬癸 「谋略大」 | − |

- 오행 단위로 묶으면 더 고르다: 三命通會 卷七 火 「其性急」, 金 「其性剛，其情烈」, 土 「其性重，其情厚」, 木 「其情和」.
- ⇒ **예측 E1: 火·金 일간 > 木·水·土 일간 (강도).**
- 음양 단위는 원전끼리 부딪친다. 丁·辛이 한 책에서는 유하고 다른 책에서는 강하다. 그래서 음양으로는 예측하지 않는다.

### 2-2. 일간의 세기(신강·신약) ✔

- A 淵海子平 論性情: 「日干强，则妄诞，执一自傲；日干弱，则退缩怕羞」.
- A 淵海子平 女命: 「身强…性多急躁」 / 「身弱，主性纯粹而温柔」.
- ⇒ **예측 S1: 신강 > 신약 (강도, 자기과시).** 엔진의 `strength_score`로 바로 잴 수 있다.

### 2-3. 십신 — 사주에서 무엇이 강한가 ✔ (가장 촘촘한 층)

| 십신 | A급 원문 | 강도 | 폭 | 먹기 | 씀씀이 | 향락 | 과시 |
|---|---|---|---|---|---|---|---|
| **식신** | 「食神善能饮食、体厚而喜謳歌」(相心賦) · 「食神多而好饮食」 · 「优游自足」 | − | | **+** | | +(약) | |
| **상관** | 「伤官主人多才艺、傲物气高」 · 「伤官伤尽，多艺多能」 · 「恃己凌人心好胜」 | +(약) | **+** | | | | **+** |
| 편재 | 「偏财主人慷慨」 · 「慷慨风流」 · 「嗜酒贪花」(偏正財) · 「别立家园三两处」 | | +(약) | | **+** | **+** | |
| 정재 | 「勤俭慳吝」 · 「行事俭约…惟有悭吝」 | | − | | **−** | | |
| 정관 | 「正官仁德性情纯」 · 「性优游而仁慈宽大」 | **−** | | | | | |
| **편관(칠살)** | 「情性如虎、急躁如风」 · 「性急伶俐」 · 「喜酒色而偏争好斗」 | **++** | | | | + | |
| 정인 | 「多智慧、丰身自在心慈」 · 「能饮食」 · 「吝财」 「括囊」 | − | | **+** | − | | |
| 편인(효) | 「好学艺而多学少成」 · 「始勤终惰」 | | +(넓게 배우나 오래 못 감) | | | | |
| 비겁·양인 | 「阳刃重逢…心性气高强」 · 「性刚果毅」 · 「心高下贱…贪婪」 | **+** | | | 엇갈림 | | + |

- ⇒ **예측 T1**: 편관 강함 → 강도 +.
- **T2**: 식신(과 정인) 강함 → 먹기 즐김 +.
- **T3**: 상관·편인 강함 → 폭 +.
- **T4**: 편재 + / 정재 − → 씀씀이.
- **T5**: 편재·편관 → 향락 +.
- 십신은 생시 없이도 년·월·일주로 계산된다. 다만 시주 몫은 빠진다.

### 2-4. 신살 ✔ (이번에 새로 나온 층)

- A 三命通會 卷三 三奇: 「主人精神异常，襟怀卓越，**好奇尚大，博学多能**」 → 폭 ++.
- A 三命通會 驛馬: 「好游脚」. 淵海子平: 「八字四马总交驰…身閒心不定」 → 폭·이동 +.
- A 淵海子平 魁罡: 「人带魁罡性必强」 「临事有断，惟是好杀」 → 강도 +.
- A 淵海子平 華蓋: 「幽閒潇洒之人」 → 폭 0, 고요함 쪽.
- 지지: 「辰多好斗」(강도 +) · 「辰未人好食，丑人清省」(B, 窮通寶鑑, 먹기 +) · 「子午卯酉全备，酒色昏迷」(향락 +).
- ⇒ **예측 N1**: 삼기·역마 → 폭 +.
- **N2**: 괴강 → 강도 +.
- 역마는 일지 기준으로도 계산된다. 삼기는 년·월·일 천간 배열로 계산된다.

### 2-5. 조후(차고 더움·마르고 습함) ✔ — 원문은 기질을 말하지 않는다

- 滴天髓 寒暖·燥濕 원문과 원주는 명식의 성패를 말할 뿐이다. 가장 가까운 문장은 원주 「過於濕者，滯而無成，過於燥者，烈而有禍」이다.
- 기질 서술은 B급에만 있다.
  - 任注: 「丙生季夏，火炎土燥…性情乖张…争躁如风火」, 「激其猛烈之性…好勇」.
  - 窮通寶鑑: 「金水性寒寒到底，凄凉…」.
- ⇒ **예측 C1 (B급)**: 덥고 마른 사주 → 강도 +, 차고 습한 사주 → 강도 −.
- ⚠ 이 예측은 태어난 계절과 거의 같다(여름생이 덥다). 사주 고유의 신호라고 말하려면 **계절 주효과를 뺀 뒤 일간 × 계절의 상호작용**이 남아야 한다. 예: 같은 여름생 안에서 丙·丁이 壬·癸보다 더 강렬한 쪽인가.

### 2-6. 사주 전체가 고른가·치우쳤는가 ✔

- A 滴天髓 性情 원문: 「五氣不戾，性情中和；濁亂偏枯，性情乖逆」.
- B 任注: 「不偏不枯…为人宽厚和平」.
- A 滴天髓 性情: 「用神多者，情性不常」.
- B 任注: 「用神无所着落…多迁变之心」.
- ⇒ **예측 B1**: 치우친 사주 → 강도 +(乖逆), 고른 사주 → 강도 −.
- **B2**: 용신이 흩어진 사주 → 폭·변화 +.
- 「치우침」은 엔진의 오행 가중 비중으로 정의할 수 있다. 다만 지표 정의는 사전등록 때 정한다.

### 2-7. 격국 — 비어 있음

- 『子平真詮』 원문을 열지 못해 채우지 못했다.
- 다른 책의 격국 문장은 대부분 그 격의 십신 서술과 같다. 예: 「正财之格，主人诚实，行事俭约」.
- 그래서 격국은 당분간 2-3 십신 칸으로 대신한다.

## 3. 맛 종류 — 여전히 근거 0

- 이번 조사 범위를 넓혀도 「어느 범주가 어느 맛(酸苦甘辛鹹)을 좋아한다」는 문장은 없었다.
- 원전이 음식에 대해 말하는 것은 **얼마나 잘 먹고 즐기나**(식신·인수·辰未)와 **술**(편재·편관·인왕신강)뿐이다.

## 4. 엔진 `SIPSIN_FLAVOR_MAP_V2`와 원전 대조

| 십신 | 엔진 방향 | 원전 A급과 | 판정 |
|---|---|---|---|
| 상관 | maximalist+ · adventurous+ · aesthetic+ · comfort− | 多才艺 · 傲物气高 | **맞음**(폭·과시) |
| 정관 | comfort+ · maximalist− · adventurous− | 仁德性情纯 · 优游仁慈宽大 | **맞음**(유함) |
| 정재 | comfort+ · budget− · adventurous− | 勤俭慳吝 · 俭约 | **맞음**(씀씀이 −) |
| 편재 | adventurous+ · social+ · budget+ | 慷慨 · 风流 · 嗜酒贪花 | **맞음** |

| 편관 | energetic+ · adventurous+ · comfort− | 急躁如风 · 好斗 | **맞음**(강도) |

- ⇒ 엔진에서 원전 근거가 없는 것은 **맛 칸(bitter)** 쪽이다. 성향 칸은 대부분 원전과 같은 방향이다.
- 엔진은 바꾸지 않았다(LEO 승인 사항, 게이트 가중치 0).

## 5. 검증으로 가는 순서 (제안)

1. 원전 근거가 가장 촘촘하고 서로 엇갈리지 않는 예측부터 본다: **T1**(편관 → 강도), **T2**(식신 → 먹기 즐김), **T3**(상관·편인 → 폭), **S1**(신강 → 강도), **N1**(삼기·역마 → 폭).
2. 일간 단위(E1)는 원전끼리 엇갈리는 칸이 있어 뒤로 둔다.
3. 조후(C1)는 계절 효과와 섞이고 근거가 B급이라 마지막에 본다.
4. 모든 예측은 「직접 매칭」이 아니라 **기울기**다(LEO 11-24). 판정은 「그 범주의 평균이 그 방향으로 기우는가」이다.
5. 검증할 자료(생일 + 성향·선호)는 아직 없다. 자료 경로는 LEO 결정 사항이다.

## 6. 한계

- wikisource 간체 판본만 봤고 인쇄본 대조는 하지 않았다. 『子平真詮』은 미확인이다.
- 「찾지 못함」은 「없음」이 아니다.
- 원문 낱말 → 축 번역(§1)은 flavor의 해석이다. 검증 전에 이 규칙을 그대로 사전등록한다.
- 원전의 기질 서술에는 도덕 평가(小人·奸)가 섞여 있다. 이런 표현은 제품 문구에 쓰지 않는다.
