## 0-1. 다섯 레이어 (LEO 2026-11-06 확인)

LEO 11-05 「일반적 구분 축 레이어 하나 추가하는 건 동의, 아주 중요한 발견」, 11-06 「지금 정리가 좋은 거 같아」.

| 레이어 | 내용 | 모델 기호 |
|---|---|---|
| 1 | 사주 구분 — 일 기준(일간 10종·일주 60종, 생시 미상이 많아서). 시를 알면 일주×시지 720종. 과거 내부 구분: 3/12 엔진(flavor repo 730ba75) 일간 10종(L1)·격국×신강약 20종(L2) | saju_features |
| 2 | 타고난 일반 취향 축 — 제품과 무관한 축(신맛·쓴맛·단맛·강도·새것 선호 등)의 타고난 값 | I_u ∈ T |
| 3 | 환경으로 틀어진 값 — 같은 축 위의 지금 값. 틀어짐 = 3 − 2 | A_u, D_u = A_u − I_u |
| 4 | 제품군 — 일반 축을 그 제품군의 맛 축으로 번역(커피: 산미/진하기/우유·단맛) | P_c |
| 5 | 세부 제품 — 실제 브랜드·메뉴 좌표 | x_i |

- 가설 방향(LEO 11-06): 타고난 취향이 먼저 있고, 환경 때문에 틀어진다. 일부는 남고 일부는 바뀐다.
- 일반 축(2·3)이 있어야 타고난 값과 지금 값을 같은 자리에서 비교할 수 있고, 제품군 간 전이도 이 축을 거친다. 태어날 때 없던 제품에 대한 취향도 이 축으로만 설명된다.
- 그래서 §3 열린 질문 4(T를 9D로 둘지 감각 축을 더할지)는 「감각·성향 일반 축이 필요하다」로 방향이 정해졌다. 축 목록 확정은 다음 단계다.

## 1. 모델

```
공통 취향 공간 T (현행 9D에서 시작)
  I_u  = 타고난 점    = g(saju_features)   ← 게이트 닫힘 동안 g ≡ 모집단 평균(상수)
  A_u  = 지금 점      ~ I_u + δ(cohort) + 관측 보정(퀴즈·제품 반응)
  D_u  = 틀어짐       = A_u − I_u          ← 저장 대상 (신규)
제품군 c:  P_c : T → axes_c                 ← 번역표 (커피 axes = 산미 / 바디 / 우유·단맛)
제품   i:  x_i ∈ axes_c                     ← 실제 SKU 좌표
추천:      argmin_i ‖P_c(A_u) − x_i‖  (또는 우도 기반 순위)
전이:      커피 반응 → A_u 갱신 → P_c'(A_u)로 다른 제품군 추천 갱신
```

- **게이트 정합**: `I_u`가 상수이면 `D_u = A_u − 상수`이고 엔진은 지금처럼 설문 100%로 동작한다. 사주 개방은 기존 하네스(`scripts/validate_saju_signal.py`, Stage 2 n≥200)가 판정한다. 기준은 바꾸지 않는다.
- **δ(cohort)**: `engines/coldstart.py`의 연령·성별 사전값(Barragán 2018 방향성)이 이미 「틀어짐 사전값」의 첫 사례다. 이것을 제품군 축이 아니라 T 위의 δ로 승격하는 것이 핵심 리팩터다.
